# RB-003 - Approved software installation request

**Agent:** `service-desk`
**Match terms:** install, software, application, license, setup

## Symptoms

Approved software installation request, reported through the portal, email or a monitoring alert.

## Procedure

| # | Step | Tool | write |
|---|---|---|---|
| 1 | Confirm the title appears on the approved catalogue | `kb_search` | false |
| 2 | Reply with the self-service portal steps | `ticket_comment` | false |

## Notes

Titles outside the approved catalogue are a request-access matter, not service-desk.
